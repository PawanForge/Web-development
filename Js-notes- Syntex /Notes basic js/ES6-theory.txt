
🌟 ES6 (ECMAScript 2015) – Complete Explanation

🔹 What is ES6?

ES6 is a major update of JavaScript that introduced modern syntax and features to write:

cleaner code

less boilerplate

more readable & maintainable programs


Before ES6 → ES5 (old style)
After ES6 → modern JavaScript (used in React, Node, etc.)


---

1️⃣ let and const (Block Scoped Variables)

❌ Problem with var

if (true) {
  var x = 10;
}
console.log(x); // 10 (leaks outside block)

✅ let (can change value)

let x = 10;
x = 20; // allowed

✅ const (cannot reassign)

const y = 30;
// y = 40 ❌ error

🔹 Block Scope

if (true) {
  let a = 5;
}
// console.log(a) ❌ error

📌 Use

let → value changes

const → fixed reference (preferred)



---

2️⃣ Arrow Functions (=>)

ES5 Function

function add(a, b) {
  return a + b;
}

ES6 Arrow Function

const add = (a, b) => a + b;

Single Parameter

const square = x => x * x;

Multiple Lines

const sum = (a, b) => {
  let result = a + b;
  return result;
};

🔹 Key Difference (this)

Arrow functions do not have their own this.

function normal() {
  console.log(this);
}

const arrow = () => {
  console.log(this);
};

📌 Use arrow functions in callbacks & React components


---

3️⃣ Template Literals (`)

ES5

let name = "Pawan";
console.log("Hello " + name);

ES6

let name = "Pawan";
console.log(`Hello ${name}`);

Multi-line String

let msg = `
Hello
Welcome to ES6
`;

📌 Cleaner & readable


---

4️⃣ Default Parameters

function greet(name = "Guest") {
  return `Hello ${name}`;
}

greet();        // Hello Guest
greet("Pawan"); // Hello Pawan

📌 Avoid undefined values


---

5️⃣ Destructuring (Array & Object)

🔹 Array Destructuring

const arr = [10, 20, 30];

const [a, b] = arr;
console.log(a, b); // 10 20

🔹 Object Destructuring

const user = {
  name: "Pawan",
  age: 22
};

const { name, age } = user;

Rename Variable

const { name: userName } = user;

📌 Very common in React props


---

6️⃣ Spread Operator (...)

Copy Array

const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];

Copy Object

const user = { name: "Pawan" };
const newUser = { ...user, age: 22 };

Prevent Mutation

const updatedUser = { ...user, name: "Aman" };

📌 Important for immutability


---

7️⃣ Rest Operator (...)

Collect Remaining Values

function sum(...numbers) {
  return numbers.reduce((a, b) => a + b);
}

sum(1, 2, 3, 4); // 10

📌 Used in functions & destructuring


---

8️⃣ Enhanced Object Literals

ES5

let name = "Pawan";
let user = {
  name: name
};

ES6

let name = "Pawan";
let user = { name };

Method Shortcut

const user = {
  greet() {
    console.log("Hello");
  }
};


---

9️⃣ Modules (import / export)

Export

export const add = (a, b) => a + b;

Import

import { add } from "./math.js";

Default Export

export default function hello() {}

📌 Helps in code splitting & reuse


---

🔟 Classes

ES5 Constructor Function

function Person(name) {
  this.name = name;
}

ES6 Class

class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello ${this.name}`);
  }
}

const p1 = new Person("Pawan");

📌 Cleaner OOP syntax


---

1️⃣1️⃣ Promises

Problem: Callback Hell

Solution: Promise

const promise = new Promise((resolve, reject) => {
  resolve("Success");
});

promise.then(data => console.log(data));

States

pending

fulfilled

rejected


📌 Foundation of async/await


---

1️⃣2️⃣ for...of Loop

const arr = [10, 20, 30];

for (let value of arr) {
  console.log(value);
}

📌 Iterates values (not index)


---

1️⃣3️⃣ Map & Set

Map (key-value)

const map = new Map();
map.set("name", "Pawan");
map.get("name");

Set (unique values)

const set = new Set([1, 2, 2, 3]);
console.log(set); // 1,2,3


---

1️⃣4️⃣ Symbol

const id = Symbol("id");

📌 Creates unique identifiers
