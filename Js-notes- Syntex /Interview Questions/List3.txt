1. Imperative vs Declarative

Imperative Programming

You tell the computer how to do something step by step.

You control loops, steps, and logic manually.

Example:


const numbers = [1, 2, 3, 4];
let doubled = [];
for(let i = 0; i < numbers.length; i++){
  doubled.push(numbers[i] * 2);
}
console.log(doubled); // [2, 4, 6, 8]

You handle each step yourself.


Declarative Programming

You tell the computer what you want.

The computer decides how to achieve it.

Example:


const numbers = [1, 2, 3, 4];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6, 8]

You only say the goal, not the steps.


Memory Tip:

Imperative = “Do this, then that”

Declarative = “I want this result”

2. Splice vs Slice

slice()

Used to copy part of an array.

Does not change the original array.

Syntax: array.slice(start, end)

Example:


const arr = [1, 2, 3, 4, 5];
const part = arr.slice(1, 4);
console.log(part); // [2, 3, 4]
console.log(arr);  // [1, 2, 3, 4, 5]

splice()

Used to add, remove, or replace elements.

Changes the original array.

Syntax: array.splice(start, deleteCount, item1, item2, ...)

Example (remove elements):


const arr = [1, 2, 3, 4, 5];
const removed = arr.splice(1, 2); // remove 2 elements starting at index 1
console.log(removed); // [2, 3]
console.log(arr);     // [1, 4, 5]

Example (add elements):


arr.splice(1, 0, 99, 100); // add 99,100 at index 1
console.log(arr); // [1, 99, 100, 4, 5]

Memory Tip:

slice = copy (non-destructive)

splice = change (destructive)

3. map, filter, reduce, includes

map()

Changes every element of an array.

Returns a new array.


[1, 2, 3].map(x => x * 2); // [2, 4, 6]

filter()

Keeps elements that pass a test.

Returns a new array.


[1, 2, 3, 4].filter(x => x % 2 === 0); // [2, 4]

reduce()

Combines all elements into a single value.


[1, 2, 3, 4].reduce((sum, x) => sum + x, 0); // 10

includes()

Checks if a value exists in an array.

Returns true or false.


[1, 2, 3].includes(2); // true
[1, 2, 3].includes(5); // false

Memory Tip:

map = change all

filter = select

reduce = combine into one

includes = check

4. Event Bubbling & Capturing

Event Bubbling

Event starts at child element and moves up to parent elements.

Default behavior in JavaScript.

Example:


document.getElementById('parent').addEventListener('click', () => console.log('Parent clicked'));
document.getElementById('child').addEventListener('click', () => console.log('Child clicked'));

Clicking child logs:


Child clicked  
Parent clicked

Event Capturing

Event starts at parent and moves down to child.

To enable: addEventListener(event, handler, true)

Example:


document.getElementById('parent').addEventListener('click', () => console.log('Parent clicked'), true);

Clicking child logs:


Parent clicked  
Child clicked

Memory Tip:

Bubbling = child → parent (inside → outside)

Capturing = parent → child (outside → inside)
