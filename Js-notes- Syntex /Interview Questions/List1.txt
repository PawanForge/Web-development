

1. <!DOCTYPE>

The <!DOCTYPE> declaration tells the browser which version of HTML you are using. This ensures that the page renders in standards mode, avoiding inconsistencies across browsers.
Example:

<!DOCTYPE html>


---

2. Metadata (<meta>)

Metadata gives extra information about the page, such as character encoding or descriptions for SEO. It does not show on the page but helps browsers and search engines.
Example:

<meta charset="UTF-8">
<meta name="description" content="My webpage">


---

3. <span>

<span> is an inline element used to style small pieces of text without affecting layout.
Example:

<p>Hello <span style="color:red">World</span></p>


---

4. async Attribute

The async attribute on a <script> tag makes the script load in the background. This improves page speed because the script does not block the rest of the page from loading.


---

5. Elements vs Tags

Tag: The markup like <p> or </p>

Element: The full structure including start and end tag and content, e.g., <p>Hello</p>



---

6. Inline vs Block Elements

Inline elements stay on the same line, and their width and height depend on content. Examples: <span>, <a>

Block elements start on a new line, take full width, and their width/height can be set. Examples: <div>, <p>



---

7. Replaced vs Non-Replaced Inline Elements

Replaced: The browser replaces the element with external content, like <img> or <input>. Width and height can be set.

Non-Replaced: Content is inside the tag, like <span> or <a>. Width and height cannot be set.



---

8. HTML Attributes

Attributes provide extra information about an element. Examples include id, class, href, src, alt, and style. They control behavior or appearance.


---

9. Global Attributes

These can be used on any element, like id, class, style, title, hidden, data-*.


---

10. Data Attributes

Custom attributes that start with data-. They store extra data on an element, accessible in JavaScript via element.dataset.
Example:

<button data-id="101">Click</button>


---

11. Semantic HTML

Semantic elements clearly describe the meaning of the content, making it better for SEO and accessibility. Examples: <header>, <nav>, <section>, <article>, <aside>, <footer>


---

12. <img> Display Value

By default, <img> is inline-block, meaning it stays in the line but width and height can be set. You can change it to block if you want it to start on a new line.


---

13. Inline Elements Height/Width

Inline elements cannot have width or height applied because they follow text flow. Use inline-block or block if you need to control size.


---

CSS

14. Box Model

Every element is a box with content → padding → border → margin. Width and height by default apply to content only. Use box-sizing: border-box to include padding and border in width.


---

15. Position Property

Controls how elements are positioned. Default is static (normal flow). Others: relative, absolute, fixed, sticky.


---

16. Relative vs Absolute Position

Relative: Moves from its own position, keeps space.

Absolute: Moves relative to the parent (or body if none), does not keep space.



---

17. em vs rem

em is relative to parent font size

rem is relative to root font size
Use rem for consistent sizing across the page.



---

JavaScript

18. Parameters vs Arguments

Parameter: variable in function definition

Argument: actual value passed to function


function greet(name){} // name is parameter
greet("Alice"); // "Alice" is argument

19. Function Scope vs Block Scope vs Inline Scope

Function scope: variable is accessible inside the function only

Block scope: variable inside {}

Inline scope: variable inside small inline function or callback



---

Graphics

20. SVG vs Canvas

SVG: Vector graphics, scalable, DOM-accessible, good for icons and charts

Canvas: Pixel-based graphics, fast, good for games, animations, not DOM-accessible



---

✅ Tips / Memory Lines

Inline elements follow text flow

Block elements start on a new line

Semantic tags describe meaning

Relative = keeps space; Absolute = removes space

em = parent; rem = root
