
1️⃣ Callback – Interview Preparation

👉 What is a Callback?

A function passed as an argument and executed later, usually after an async task.

function fetchData(callback) {
  setTimeout(() => {
    callback("Data received");
  }, 1000);
}

fetchData((data) => {
  console.log(data);
});

🧠 Why used?

JS is non-blocking

Used before Promises existed



---

❌ Callback Hell (Very important)

login(user, () => {
  getProfile(() => {
    getPosts(() => {
      getComments(() => {
        // 😵 nightmare
      });
    });
  });
});

Interview Question:

👉 What problem do callbacks have?

Answer:

Callback hell (nested code)

Hard to read

Difficult error handling

Poor maintainability

2️⃣ Promise – Interview Preparation

👉 What is a Promise?

A Promise represents a future value.

States:

pending

fulfilled

rejected


const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Success");
  }, 1000);
});

promise.then(result => console.log(result));


---

🧠 Why Promises?

✔ Cleaner than callbacks
✔ Better error handling
✔ Chaining possible


---

🔗 Promise Chaining

fetchUser()
  .then(user => fetchPosts(user.id))
  .then(posts => fetchComments(posts[0].id))
  .catch(error => console.log(error));

👉 Single .catch() handles all errors


---

3️⃣ Async / Await – Interview Preparation

👉 What is async/await?

Syntactic sugar over Promises
Makes async code look sync

async function getData() {
  const data = await fetchData();
  console.log(data);
}


---

❌ Common Interview Trap

async function test() {
  return "Hello";
}

console.log(test());

Output?

👉 Promise { "Hello" }

🧠 async always returns a Promise


---

🛑 Error Handling

async function getUser() {
  try {
    const user = await fetchUser();
    console.log(user);
  } catch (error) {
    console.log(error);
  }
}

🔁 Conversion Questions (VERY IMPORTANT)

Callback ➝ Promise

function fetchData() {
  return new Promise((resolve) => {
    setTimeout(() => resolve("Data"), 1000);
  });
}

Promise ➝ Async/Await

async function getData() {
  const data = await fetchData();
  console.log(data);
}

👉 Interviewers LOVE this.


---

🧠 Comparison (One-liner)

Feature	Callback	Promise	Async/Await

Readability	❌ Bad	👍 Better	✅ Best
Error Handling	❌ Hard	👍 Easy	✅ Very Easy
Nested code	❌ Yes	❌ Less	❌ No
