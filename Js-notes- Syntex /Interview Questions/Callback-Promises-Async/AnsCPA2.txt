
Promise is a technique used to reduce callback hell and handle asynchronous operations in a clean and readable way.

A Promise has three states:

1. Pending – initial state, execution is in progress


2. Fulfilled – operation completed successfully


3. Rejected – operation failed or an error occurred



When a Promise is fulfilled, we handle the result using .then()
When a Promise is rejected, we handle the error using .catch()

Promises provide:

Cleaner syntax

Better error handling

Improved readability

Easier chaining of async operations



---

🧠 Simple Example

const promise = new Promise((resolve, reject) => {
  let success = true;

  if (success) {
    resolve("Operation successful");
  } else {
    reject("Operation failed");
  }
});

promise
  .then(result => console.log(result))
  .catch(error => console.log(error));


---

🎯 One-Line Interview Answer

> “Promises were introduced to avoid callback hell by providing a clean syntax and better error handling for asynchronous operations.”
