🔹 Callback Function 

✅ Meaning (1 Line)

> A callback is a function passed to another function and called after work is finished.




---

1️⃣ Simple Example

function work(callback) {
  console.log("Work done");
  callback();
}

function nextStep() {
  console.log("Next step");
}

work(nextStep);

Easy Explanation

nextStep → callback function

It runs after work is completed



---

2️⃣ Why Callback Is Used?

👉 JavaScript runs fast and does not wait for slow tasks.

Callbacks help to:

wait for task completion

run code in correct order



---

3️⃣ Callback in Async (Main Use)

Example: setTimeout

console.log("Start");

setTimeout(() => {
  console.log("Async task done");
}, 2000);

console.log("End");

What happens?

"Start" prints

"End" prints

After 2 sec → callback runs


✔ Callback runs after async task finishes


---

4️⃣ Without Callback (Problem)

let data;

setTimeout(() => {
  data = "Result";
}, 2000);

console.log(data); // undefined

❌ Async not finished yet


---

5️⃣ With Callback (Correct Way)

function getData(callback) {
  setTimeout(() => {
    callback("Result");
  }, 2000);
}

getData((data) => {
  console.log(data);
});

✔ Callback waits for result


---

6️⃣ Ready Method (Very Easy)

Meaning

> Ready method runs code only when everything is ready.



Example (DOM Ready)

document.addEventListener("DOMContentLoaded", () => {
  console.log("Page ready");
});

✔ Callback runs after page loads
✔ Avoids errors


---

🧠 Easy Memory Trick

📦 Do work
📞 Call back when done


---

🎯 Interview One-Line Answer

> A callback is a function passed as an argument and executed later, mainly used to handle asynchronous operations and maintain execution order.
