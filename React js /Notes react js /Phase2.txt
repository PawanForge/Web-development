React.js – Components & JSX (How, Why, Purpose & Learning Notes)

These notes explain WHAT, WHY, HOW, and PURPOSE of each topic, written in simple language and based only on topics from your images. Small code examples are included for learning.


---

1. Component

What is a Component?

A component is a small, reusable part of the UI.


Why Components are Used?

To divide UI into small pieces.

To make code easy to manage and reuse.


Purpose of Components

Reusability

Clean structure

Easy maintenance


How Components Work?

Each UI part is written as a separate function.


Example UI Parts

Header

Sidebar

Main Content

Footer



---

2. Component Naming Rule

What is the Rule?

Component names must start with a capital letter.


Why Capital Letter is Needed?

React treats lowercase names as HTML tags.


Purpose

Helps React identify components correctly.


✅ Correct: App, Login ❌ Incorrect: app, login


---

3. Function Based Component

What is it?

A component written using a JavaScript function.


Why It Is Used?

Simple and easy to understand.

Less code compared to class components.


Purpose

To create UI using functions.


How It Works?

Function returns JSX.


function App() {
  return (
    <div>
      <h1>First Component</h1>
    </div>
  );
}

export default App;


---

4. Types of Components

Function Based Component

Easy

Modern

Most used


Class Based Component

Older method

More complex

Rarely used now



---

5. Import and Export

What is Export?

Makes a component available to other files.


Why Export is Used?

To reuse components.


How Export Works?

export default Login;

What is Import?

Used to bring component into another file.


How Import Works?

import Login from './Login';


---

6. Component Usage

Purpose

To use one component inside another.


How It Works?

import Login from './Login';

function App() {
  return (
    <div>
      <Login />
    </div>
  );
}

export default App;


---

7. JSX

What is JSX?

JSX means JavaScript XML.

Allows HTML inside JavaScript.


Why JSX is Used?

Makes UI code easy and readable.


Purpose

To write UI code simply.



---

8. JSX Rules

Why Rules are Needed?

JSX follows JavaScript syntax.


Important Rules

Only one parent element

All tags must be closed

Use className instead of class



---

9. JSX with Curly Braces {}

What are Curly Braces?

Used to write JavaScript inside JSX.


Why Curly Braces are Used?

To display dynamic data.


Purpose

Connect JavaScript logic with UI.



---

10. JSX Curly Braces – Examples

Variable Example

function App() {
  const name = "React";
  return <h1>Hello {name}</h1>;
}


---

Expression Example

function App() {
  return <h2>{10 + 20}</h2>;
}


---

Function Example

function App() {
  function greet() {
    return "Welcome";
  }

  return <h3>{greet()}</h3>;
}


---

11. JSX vs Without JSX

With JSX

return <h1>Hello</h1>;

Without JSX

return React.createElement('h1', null, 'Hello');

Why JSX is Better?

Easy to read

Less code



---

12. How to Learn These Topics (Simple Way)

1. Understand components first


2. Practice function components


3. Learn JSX rules


4. Practice curly braces examples


5. Build small UI parts




---

13. Final Summary

Components divide UI into small parts.

Function components are most used.

JSX allows HTML in JavaScript.

Curly braces add dynamic data to UI.

Import & export connect components.
