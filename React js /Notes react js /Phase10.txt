
1️⃣ What is Nested Looping?

Nested looping means using one loop inside another loop.

In React, nested looping is commonly done when:

You have nested data (arrays inside objects or arrays inside arrays)

Example:

Colleges → Students

Categories → Products

Countries → Cities



👉 We usually use .map() for looping in React JSX.


---

2️⃣ Why Do We Use Nested Looping in React?

We use nested looping because:

Real-world data is hierarchical

A single loop is not enough to display child data

Helps display structured UI dynamically


Example:

One college has multiple students
➡ First loop: colleges
➡ Second loop: students of each college


---

3️⃣ Purpose of Nested Looping

✔ To display parent–child relationships
✔ To avoid hard-coded UI
✔ To make components reusable and dynamic
✔ To render complex JSON data easily


---

4️⃣ How Nested Looping Works in React

Step-by-step:

1. Store data in an array of objects


2. Each object may contain another array


3. Use .map() for the outer array


4. Inside it, use another .map() for the inner array


5. Return JSX from both loops


6. Always provide a key




---

5️⃣ Syntax of Nested Looping

array.map((item, index) => (
  <div key={index}>
    {item.childArray.map((child, i) => (
      <p key={i}>{child.property}</p>
    ))}
  </div>
))


---

6️⃣ Example Code (Clean & Correct)

📌 Data Structure

function App() {

  const collegeData = [
    {
      name: "FET Alwar",
      city: "Alwar",
      students: [
        { name: "PJ", age: 29 },
        { name: "PC", age: 26 }
      ]
    },
    {
      name: "IIT Delhi",
      city: "Delhi",
      students: [
        { name: "SS", age: 30 }
      ]
    }
  ];


---

📌 JSX with Nested Looping

return (
    <div>
      <h1>Nested Looping with Components</h1>

      {collegeData.map((college, index) => (
        <div key={index}>
          <h2>College Name: {college.name}</h2>
          <h3>City: {college.city}</h3>

          <ul>
            {college.students.map((student, i) => (
              <li key={i}>
                Name: {student.name}, Age: {student.age}
              </li>
            ))}
          </ul>
        </div>
      ))}

    </div>
  );
}

export default App;

🔹 Outer .map() (Colleges Loop)

collegeData.map((college, index) => (

Loops through each college

key={index} helps React identify elements



---

🔹 Inner .map() (Students Loop)

college.students.map((student, i) => (

Runs inside the college loop

Displays students related to that specific college

This is the nested loop



---

🔹 JSX Rendering

<h2> → College name

<h3> → City

<ul> → Student list

<li> → Individual student details



---

8️⃣ Important Rules in Nested Looping

✅ Use .map() instead of for loop
✅ Always add a key
✅ Parent loop renders parent data
✅ Child loop renders related child data
✅ Keep JSX readable and clean
