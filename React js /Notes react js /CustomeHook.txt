1️⃣ What is a Custom Hook?

👉 A custom hook is your own hook that you create to reuse logic.

It is a normal JavaScript function

Its name must start with use (useToggle)

Inside it, you can use React hooks like useState, useEffect


💡 Think of it as:

> “Logic ko ek jagah likho, aur jahan chaaho use karo”




---

2️⃣ Why do we use Custom Hooks? (Purpose)

❌ Problem without custom hook

Imagine you need toggle logic in many components:

const [value, setValue] = useState(true);

function toggleValue(val) {
  if (typeof val !== "boolean") {
    setValue(!value);
  } else {
    setValue(val);
  }
}

You would have to copy-paste this code everywhere 😖
❌ Bad practice
❌ Hard to maintain


---

✅ Solution: Custom Hook

You put this logic once in useToggle and reuse it everywhere.

✅ Clean code
✅ Reusable logic
✅ Easy to maintain
✅ Professional React pattern

4️⃣ How You Use Custom Hook in Component

📌 App.js

const [value, toggleValue] = useToggle(true);

👉 Same style as useState

true → default value

value → current state

toggleValue → function



---

Buttons Behavior 👇

<button onClick={toggleValue}>Toggle Head</button>

✔ Toggles heading (show ↔ hide)


---

<button onClick={() => toggleValue(false)}>Hide Heading</button>

✔ Force hide heading


---

<button onClick={() => toggleValue(true)}>Show Heading</button>

✔ Force show heading


---

Conditional Rendering

{ value ? <h1>custom hooks in react js</h1> : null }

👉 If value === true → show heading
👉 If value === false → hide heading


---

5️⃣ When Should You Create a Custom Hook?

Create a custom hook when:

✅ Same logic used in multiple components
✅ Logic is state + function based
✅ You want clean & readable components

Examples:

useToggle

useFetch

useDebounce

useLocalStorage
