

1. What is Looping in JSX?

Looping in JSX means:

> Repeating UI elements dynamically by iterating over an array of data.



In React, we often receive lists of data (users, products, skills, items) and need to display them on the screen.


---

2. Why Looping is Required in React?

Looping is required because:

Data is mostly dynamic

We don’t know how many items will come

Manual writing of JSX is not possible

Used for real-time data rendering


✔ Clean code
✔ Reusable UI
✔ Dynamic rendering


---

3. Why We Cannot Use for Loop in JSX?

❌ for, while loops are statements
❌ JSX only allows expressions
❌ Loops do not return JSX

Therefore, React uses map()


---

4. What is map() Function?

map() is a JavaScript array method.

Definition:

> map() loops over an array and returns a new array.




---

5. Why map() is Perfect for JSX?

Because:

It returns an array

JSX can render arrays

Each iteration returns JSX

Clean & declarative syntax


✔ React standard
✔ Widely used
✔ Efficient rendering


---

6. Syntax of map()

array.map((item, index) => {
  return JSX;
});

Short syntax:

array.map(item => JSX)


---

7. Looping Code Starts (Basic Example)

Step 1: Create Array

const users = ["Anil", "Sam", "Peter", "Bruce"];


---

Step 2: Use map() inside JSX

{
  users.map((name, index) => (
    <h3 key={index}>{name}</h3>
  ))
}


---

8. Explanation of Above Code

users → array

map() → loops through array

name → current element

<h3> → JSX returned

key → unique identifier



---

9. What is key in React?

Key is a special attribute used by React.

Purpose:

Identify list items uniquely

Improve rendering performance

Avoid UI bugs



---

Example:

<h3 key={index}>{name}</h3>

✔ Unique
✔ Required
✔ Prefer id over index


---

10. Looping with Object Array (Important)

Why Object Array?

Because:

Real apps use API data

API returns objects

Multiple values per item



---

11. Object Array Example

const userData = [
  { id: 1, name: "Anil", age: 29, email: "anil@test.com" },
  { id: 2, name: "Peter", age: 20, email: "peter@test.com" },
  { id: 3, name: "Sam", age: 30, email: "sam@test.com" }
];


---

12. Display Object Data Using map()

JSX Code:

{
  userData.map((user) => (
    <div key={user.id}>
      <h3>{user.name}</h3>
      <p>{user.email}</p>
      <p>{user.age}</p>
    </div>
  ))
}


---

13. Explanation (Step-by-Step)

1️⃣ React reads userData
2️⃣ map() runs for each object
3️⃣ user stores current object
4️⃣ JSX returned
5️⃣ UI updates automatically


---

14. Looping Data in Table (Most Used)

Table Code:

<table border="1">
  <thead>
    <tr>
      <th>ID</th>
      <th>Name</th>
      <th>Email</th>
      <th>Age</th>
    </tr>
  </thead>

  <tbody>
    {
      userData.map((user) => (
        <tr key={user.id}>
          <td>{user.id}</td>
          <td>{user.name}</td>
          <td>{user.email}</td>
          <td>{user.age}</td>
        </tr>
      ))
    }
  </tbody>
</table>


---

15. Why Table Needs map()?

Because:

Rows are dynamic

Data can increase/decrease

API-driven content



---

16. Difference: Array vs Object Array Loop

Array	Object Array

Single value	Multiple values
Simple lists	Real data
Easy	Practical



---

17. Common Errors ❌

❌ Forgetting key
❌ Using for loop in JSX
❌ Not returning JSX
❌ Missing wrapper element


---

18. Best Practices ✅

✔ Always use key
✔ Use id instead of index
✔ Keep JSX readable
✔ Use map only inside {}


---

👉 Yes, if each item is JSX.

Q: Why key is important?
👉 For performance and uniqueness.
