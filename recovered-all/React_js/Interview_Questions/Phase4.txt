
🔹 useRef – Interview Questions

1. What is useRef in React?
→ A hook used to access DOM elements or store mutable values without re-rendering.


2. Why useRef does not cause re-render?
→ Because updating .current does not update React state.


3. Difference between useRef and useState?
→ useState triggers re-render, useRef does not.


4. What are uncontrolled components?
→ Components where DOM handles the UI state instead of React.


5. How does useRef help in uncontrolled components?
→ It reads values directly from DOM elements.


6. Can we store previous value using useRef?
→ Yes, because ref values persist across renders.


7. When should you prefer useRef over useState?
→ When UI update is not required.




---

🔹 Controlled vs Uncontrolled – Quick Questions

1. Who controls data in controlled components?
→ React (state)


2. Who controls data in uncontrolled components?
→ DOM


3. Which is better for real-time validation?
→ Controlled components


4. Which is better for performance in large forms?
→ Uncontrolled components

🔹 Nested Data & Rendering – Interview Questions

1. What is nested data in React?
→ Data stored in parent–child structure using arrays and objects.


2. How do you render nested arrays in JSX?
→ Using map() inside another map().


3. Why map() is allowed inside JSX but for loop is not?
→ Because map() is an expression and returns JSX.


4. What is the importance of key in nested lists?
→ Helps React optimize rendering and avoid UI bugs.

🔹 Nested Loop (Conceptual – Interview Friendly)

What is a nested loop?

> A loop inside another loop, often used to handle 2D arrays or nested data.



Example (JS logic):

for (let i = 0; i < arr.length; i++) {
  for (let j = 0; j < arr[i].length; j++) {
    console.log(arr[i][j]);
  }
}


---

Nested loop in React rendering (conceptual)

data.map(parent => (
  parent.children.map(child => (
    <p key={child.id}>{child.name}</p>
  ))
))

✔ Outer loop → parent
✔ Inner loop → child

🔹 Nested Loop – Interview Questions

1. When do we use nested loops?
→ When data is nested or multi-dimensional.


2. Time complexity of nested loop?
→ Usually O(n²) (depends on structure).


3. How nested loops relate to nested map() in React?
→ Each map() acts like a loop for nested data.




---

🔹 Expressions vs Statements (Very Important)

1. Why JSX allows expressions only?
→ Expressions return values; JSX renders values.


2. Examples of expressions in JSX
→ map(), ternary operator, logical &&


3. Why if and for not directly used in JSX?
→ They are statements, not expressions.
