

What is Fragment in React?

A Fragment in React lets you group multiple elements without adding an extra DOM node.

React components must return a single parent element. Fragment solves this without using an unnecessary <div>.


---

Why Fragment Exists (Interview Gold ⭐)

Before Fragment, developers used extra <div> wrappers:

return (
  <div>
    <h1>Title</h1>
    <p>Description</p>
  </div>
);

Problem ❌

Adds extra DOM nodes

Breaks CSS layouts (Flex, Grid)

Affects semantic HTML

Slight performance overhead


Fragment fixes this ✅


---

Basic Fragment Syntax

1️⃣ Long Syntax

import React from "react";

function App() {
  return (
    <React.Fragment>
      <h1>Hello</h1>
      <p>World</p>
    </React.Fragment>
  );
}


---

2️⃣ Short Syntax (Most Used)

function App() {
  return (
    <>
      <h1>Hello</h1>
      <p>World</p>
    </>
  );
}

⚠️ Short syntax cannot accept props


---

Fragment vs Div (Very Important)

Feature	Fragment	Div

Extra DOM node	❌ No	✅ Yes
Styling possible	❌ No	✅ Yes
Cleaner DOM	✅ Yes	❌ No
Performance	Better	Slightly lower
Semantic HTML	Maintained	Sometimes broken


Interview Line:
👉 Fragment helps avoid unnecessary DOM nodes and keeps HTML structure clean.


---

Fragment with key (Frequently Asked Question)

When rendering lists, Fragment must have a key.

❌ Wrong

items.map(item => (
  <>
    <h1>{item.title}</h1>
    <p>{item.desc}</p>
  </>
));

✅ Correct

items.map(item => (
  <React.Fragment key={item.id}>
    <h1>{item.title}</h1>
    <p>{item.desc}</p>
  </React.Fragment>
));

📌 Short syntax does NOT support key


---

Fragment in Table (Classic Interview Trap 🪤)

HTML tables don’t allow <div> inside <tr>.

❌ Wrong

<tr>
  <div>Invalid</div>
</tr>

✅ Correct using Fragment

<tr>
  <>
    <td>Name</td>
    <td>Age</td>
  </>
</tr>


---

Fragment vs Array Return

Fragment alternative:

return [
  <h1 key="1">Hello</h1>,
  <p key="2">World</p>
];

❌ Not preferred

Hard to read

Key management pain


✅ Fragment is cleaner and more readable


---

Performance Aspect (Interview Level)

Fragment does not create an actual DOM node

Helps reduce DOM depth

Better reconciliation in React Fiber


👉 Especially useful in large component trees


---

Common Interview Questions & Answers

Q1: Why use Fragment instead of div?

Answer:
Fragment avoids unnecessary DOM nodes, improves performance, and maintains semantic structure.


---

Q2: Can Fragment accept props?

Answer:
Only key is allowed, and only with <React.Fragment>, not shorthand <>.


---

Q3: Does Fragment affect styling?

Answer:
No. Fragment does not render in the DOM, so it cannot be styled.


---

Q4: When should you NOT use Fragment?

Answer:
When you need:

Styling

Layout control

CSS class or id


Use <div> then.


---

One-Line Definition (Interview Final Shot 🎯)

> React Fragment is a lightweight wrapper that allows grouping multiple elements without adding extra nodes to the DOM.
