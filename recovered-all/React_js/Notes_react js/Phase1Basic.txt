
1. What is React.js

React.js is a JavaScript library.

It is used to build user interfaces (UI).

React is mainly used for front-end web development.

React is used to create Single Page Applications (SPA).



---

2. Why React.js

React is fast because it uses the Virtual DOM.

React is easy to learn.

Learning curve is less than other UI technologies.

React has high demand in the job market.

React has a large community.



---

3. Virtual DOM

Virtual DOM is a copy of the real DOM.

React updates only the changed elements.

This improves performance and speed.



---

4. More About React

React is developed by Facebook (Meta).

Commonly used version is React 18.

After learning React, it is easy to learn React Native.

React Native is used for mobile app development.



---

5. Prerequisites for React

Basic knowledge required:

HTML

CSS

JavaScript



---

6. React Setup (Using Vite)

Vite is a build tool.

It helps to create React projects quickly.

Vite provides a fast development environment.



---

7. Why Vite is Used

Faster than older tools.

Uses modern JavaScript features.

Improves development speed.



---

8. React Project Files

index.html

Main HTML file.

Contains a div with id root.

React app renders inside this div.



---

main.jsx

Entry point of the React application.

Connects React with the browser DOM.

Renders the App component.



---

App.jsx

Main component of the application.

Written as a function component.

Returns JSX code.



---

9. JSX

JSX means JavaScript XML.

Allows writing HTML inside JavaScript.

Makes UI code easy and readable.



---

10. Components

Components are reusable UI parts.

React apps are built using components.

Function components are commonly used.



---

11. useState (Basic)

useState is a React hook.

Used to manage state.

State means data that can change.



---

12. Import and Export

export default is used to export a component.

import is used to use it in another file.



---

13. Library vs Framework

Library (React)

Developer controls the flow.

Flexible structure.


Framework

Framework controls the flow.

Fixed rules and structure.



---

14. package.json

Configuration file of the project.

Contains:

Project details

Dependencies

Scripts




---

15. Folder Structure

src folder

Contains React source code.

Standard and recommended folder.


public folder

Contains public assets.

Files are directly accessible in the browser.



---

16. node_modules

Contains installed libraries.

Created automatically.

Not edited manually.



---

17. Summary

React is a popular JavaScript UI library.

Used for building modern web applications.

Simple, fast, and widely used.
