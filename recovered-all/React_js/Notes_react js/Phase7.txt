
1. What is a Checkbox in React?

A checkbox is a form input element that allows users to select one or multiple options.

In React, checkbox values are handled using:

onChange event

event.target.checked

React state (useState)



---

2. Why Do We Use Checkboxes?

Checkboxes are used when:

Multiple options can be selected

Selecting skills, hobbies, interests

Feature selection

Preferences in forms

9. Handling Checkbox Change (Core Logic)

What is handleSkills?

It updates skills array when checkbox is checked or unchecked.


---

Code:

const handleSkills = (event) => {
  const value = event.target.value;
  const checked = event.target.checked;

  if (checked) {
    setSkills([...skills, value]);
  } else {
    setSkills(skills.filter((item) => item !== value));
  }
};


---

10. How This Logic Works (Step-by-Step)

When Checkbox is Checked ✅

setSkills([...skills, value]);

Old skills copied

New skill added



---

When Checkbox is Unchecked ❌

setSkills(skills.filter(item => item !== value));

Removes unchecked skill

Keeps remaining values

11. Complete Working Example

import { useState } from "react";

function Skills() {
  const [skills, setSkills] = useState([]);

  const handleSkills = (event) => {
    const value = event.target.value;
    const checked = event.target.checked;

    if (checked) {
      setSkills([...skills, value]);
    } else {
      setSkills(skills.filter((item) => item !== value));
    }
  };

  return (
    <div>
      <h1>Select Skills</h1>

      <input type="checkbox" value="Java" onChange={handleSkills} /> Java
      <br />

      <input type="checkbox" value="React" onChange={handleSkills} /> React
      <br />

      <input type="checkbox" value="Node" onChange={handleSkills} /> Node
      <br />

      <h3>Selected Skills:</h3>
      {skills.join(", ")}
    </div>
  );
}

export default Skills;
