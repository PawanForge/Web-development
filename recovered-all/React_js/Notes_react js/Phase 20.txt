

🔹 What is useId()?

useId() is a React hook that creates a unique ID for form elements.

import { useId } from "react";


---

🔹 Why we use useId()?

Problem before	Solution by useId()

Duplicate IDs	Generates unique IDs
Label not linked properly	Connects <label> with <input>
Accessibility issues	Screen reader support
SSR hydration error	Server & Client IDs same



---

🔹 Simple Syntax

const id = useId();


---

🔹 Best Example ✅

function UserForm() {
  const userId = useId();

  return (
    <form>
      <label htmlFor={userId + "name"}>Name</label>
      <input id={userId + "name"} />

      <label htmlFor={userId + "pass"}>Password</label>
      <input id={userId + "pass"} />
    </form>
  );
}


---

🔹 How it works?

If userId = :r2:

Field	Final ID

Name	:r2:name
Pass	:r2:pass



---

🔴 Never Do This

<li key={useId()}>Item</li> ❌


---

🟢 Correct Way for Keys

<li key={item.id}>Item</li> ✅
