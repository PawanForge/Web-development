

📌 CUSTOM HOOKS IN REACT – COMPLETE NOTES


---

🔹 What is a Custom Hook?

A Custom Hook is a JavaScript function that:

Uses one or more React hooks (useState, useEffect, etc.)

Starts with use word

Helps to reuse logic across multiple components


Example names:

useToggle
useFetch
useLocalStorage
useAuth


---

🔹 Why Custom Hooks are Needed?

Without custom hooks, we write same logic again and again:

const [show, setShow] = useState(true);
const toggle = () => setShow(!show);

Using custom hook:

const [show, toggle] = useToggle(true);

👉 Code becomes:

Shorter

Cleaner

Reusable



---

🔹 Structure of a Custom Hook

const useCustom = () => {
   // state
   // logic
   // return data / functions
}


---

📁 Example: useToggle Hook

import { useState } from "react";

const useToggle = (defaultVal = false) => {
  const [value, setValue] = useState(defaultVal);

  function toggleValue(val) {
    if (typeof val !== "boolean") {
      setValue(prev => !prev);   // toggle
    } else {
      setValue(val);           // force set
    }
  }

  return [value, toggleValue];
};

export default useToggle;


---

🔹 How to Use in Component

const [value, toggleValue] = useToggle(true);

Returned value	Meaning

value	Current state
toggleValue	Function to change state



---

🔹 Ways to Use toggleValue

Code	Result

toggleValue()	Toggle true ↔ false
toggleValue(true)	Force true
toggleValue(false)	Force false



---

📁 App.js Example

const [show, toggleShow] = useToggle(true);

<button onClick={toggleShow}>Toggle</button>
<button onClick={() => toggleShow(false)}>Hide</button>
<button onClick={() => toggleShow(true)}>Show</button>

{show && <h1>Hello World</h1>}


---

🔄 How Data Flows

Button click
    ↓
toggleShow()
    ↓
toggleValue() in hook
    ↓
setValue()
    ↓
Component re-render
    ↓
UI update


---

🔹 Important Rules

1. Custom hook name must start with use


2. Hooks only work inside:

React components

Custom hooks



3. Custom hook is logic reuse, not UI reuse




---

🔹 Advantages

Avoid code duplication

Better readability

Easier debugging

Clean architecture
