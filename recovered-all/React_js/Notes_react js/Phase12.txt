
1. How many types of styling are there in React?

In React, we mainly have 5 ways to style components:

1. Inline Styling


2. External CSS


3. CSS Modules


4. Styled Components


5. External CSS Libraries / Frameworks




---

2. Inline Styling in React

🔹 What is Inline Styling?

Styling written directly inside JSX elements using the style attribute.


---

🔹 Why Inline Styling?

Useful for dynamic styles

Conditional styling

Quick styling for small components



---

🔹 How Inline Styling Works in React?

React uses JavaScript objects, not strings

CSS properties are written in camelCase

Values are usually strings or numbers



---

🔹 Syntax Difference (HTML vs React)

❌ Regular HTML

<div style="color: blue; background-color: red;">Hello</div>

✅ React Inline Style

<div style={{ color: "blue", backgroundColor: "red" }}>
  Hello
</div>


---

🔹 Example with Variable

function App() {
  const boxStyle = {
    color: "white",
    backgroundColor: "green",
    padding: "10px"
  };

  return <div style={boxStyle}>Styled Box</div>;
}


---

🔹 Purpose / Use Case

✔ Dynamic styles
✔ Conditional UI changes
❌ Not good for large projects
❌ No hover / media queries


---

3. Dynamic and Conditional Inline Styling

🔹 What is Dynamic Styling?

Styles that change based on state, props, or conditions


---

🔹 Example: Conditional Style

function App() {
  const isLoggedIn = true;

  return (
    <h1 style={{ color: isLoggedIn ? "green" : "red" }}>
      User Status
    </h1>
  );
}


---

🔹 Example: State-Based Styling

function App() {
  const [active, setActive] = React.useState(false);

  return (
    <button
      style={{
        backgroundColor: active ? "blue" : "gray",
        color: "white"
      }}
      onClick={() => setActive(!active)}
    >
      Click Me
    </button>
  );
}


---

4. External CSS in React

🔹 What is External CSS?

Using normal .css files and importing them into React components.


---

🔹 Why Use External CSS?

Clean separation of concerns

Reusable styles

Easy to maintain

Supports hover, animations, media queries



---

🔹 How to Use External CSS?

Step 1: Create CSS File

/* App.css */
.title {
  color: blue;
  font-size: 24px;
}

Step 2: Import CSS in Component

import "./App.css";

function App() {
  return <h1 className="title">Hello React</h1>;
}


---

🔹 Important Notes

Use className instead of class

CSS is global by default



---

🔹 Purpose

✔ Best for beginners
✔ Traditional CSS approach
❌ Class name conflicts in large apps


---

5. CSS Modules

🔹 What are CSS Modules?

CSS files where class names are locally scoped to a component.


---

🔹 Why CSS Modules?

Avoid class name conflicts

Component-based styling

Better for large applications



---

🔹 How CSS Modules Work?

File Naming Rule

Button.module.css


---

🔹 Example

Button.module.css

.btn {
  background-color: purple;
  color: white;
  padding: 10px;
}

Button.jsx

import styles from "./Button.module.css";

function Button() {
  return <button className={styles.btn}>Click Me</button>;
}


---

🔹 What Happens Internally?

.btn → btn_x7k92

(Unique class generated automatically)


---

🔹 Purpose

✔ Scoped styles
✔ No conflicts
✔ Clean and maintainable


---

6. Styled Components (CSS-in-JS)

🔹 What are Styled Components?

A CSS-in-JS library where styles are written inside JavaScript files.


---

🔹 Why Styled Components?

Dynamic styling using props

Component-based styling

No external CSS files



---

🔹 Installation

npm install styled-components


---

🔹 Example

import styled from "styled-components";

const Button = styled.button`
  background-color: blue;
  color: white;
  padding: 10px;
`;

function App() {
  return <Button>Styled Button</Button>;
}


---

🔹 Dynamic Props Example

const Button = styled.button`
  background-color: ${props => props.primary ? "green" : "gray"};
`;

<Button primary>Primary</Button>


---

🔹 Purpose

✔ Advanced UI
✔ Dynamic & reusable styles
❌ Extra library dependency


---

7. External CSS Libraries / Frameworks

🔹 What are CSS Libraries?

Pre-written CSS frameworks to build UI faster.


---

🔹 Why Use Them?

Faster development

Responsive design

Pre-built components



---

🔹 Common Libraries

Library	Type

Bootstrap	Component-based
React Bootstrap	React version of Bootstrap
Material UI (MUI)	Component library
Tailwind CSS	Utility-first
Chakra UI	Component-based



---

🔹 Example: Bootstrap

npm install bootstrap

import "bootstrap/dist/css/bootstrap.min.css";

<button className="btn btn-primary">Click</button>


---

🔹 Example: Tailwind CSS

<button className="bg-blue-500 text-white px-4 py-2">
  Click Me
</button>


---

🔹 Purpose

✔ Fast UI development
✔ Responsive layouts
❌ Less customization control


---

8. Difference: React Inline Style vs Regular Inline Style

Feature	HTML Inline	React Inline

Syntax	String	JS Object
CSS Format	kebab-case	camelCase
Value Type	String only	String / Number
Dynamic	❌	✅
