
🔹 Topic: Fragment in React JS

---

🔹 What is Fragment?

A Fragment allows you to return multiple JSX elements from a component without adding an extra HTML element to the DOM.


---

🔹 Why Fragment is needed?

In React, a component must return only one parent element.

❌ Invalid JSX

return (
  <h1>Hello</h1>
  <p>World</p>
);

This gives error because React expects one root element.


---

🔹 Solution – Using Fragment

import { Fragment } from "react";

function App() {
  return (
    <Fragment>
      <h1>Fragment Example</h1>
      <p>This is React Fragment</p>
    </Fragment>
  );
}


---

🔹 Short Syntax of Fragment (Most Used) ⭐

function App() {
  return (
    <>
      <h1>Fragment Example</h1>
      <p>This is React Fragment</p>
    </>
  );
}

This does not create any extra <div> tag in HTML.


---

🔹 How Fragment works?

Using <div>

<div>
  <h1>Hello</h1>
  <p>World</p>
</div>

Using Fragment

<h1>Hello</h1>
<p>World</p>

👉 Fragment keeps HTML clean.

---

🔹 Fragment with List & Key

import { Fragment } from "react";

{items.map(item => (
  <Fragment key={item.id}>
    <h3>{item.title}</h3>
    <p>{item.desc}</p>
  </Fragment>
))}


---

🔹 When to use Fragment?

Situation	Use Fragment

Return multiple JSX elements	✅
Avoid extra <div> in HTML	✅
Improve DOM performance	✅
Apply CSS layout wrapper	❌



---

🔹 When NOT to use Fragment?

If you need styling, margin, padding, flex or grid layout – use <div>.
