

1️⃣ React Bootstrap

🔹 What is React Bootstrap?

React Bootstrap is a UI framework.

It provides ready-made components like Button, Alert, Card, etc.

It saves time and improves UI design.



---

🔹 Installation

npm install react-bootstrap bootstrap

Also import Bootstrap CSS in index.js or main.jsx:

import 'bootstrap/dist/css/bootstrap.min.css';


---

🔹 Import Components

import Button from 'react-bootstrap/Button';
import Alert from 'react-bootstrap/Alert';


---

🔹 Example

function App() {
  return (
    <>
      <h1>Add Bootstrap in React</h1>

      <Alert variant="success">
        Hello, Bootstrap Installed!
      </Alert>

      <Button variant="danger">OK</Button>
      <Button variant="success">Submit</Button>
    </>
  );
}

export default App;

✅ Note:

variant is used to change color/style

No change in event handling (onClick works same as React)

2️⃣ React Hooks – useRef

🔹 What is useRef?

useRef is a hook

Used to access DOM elements directly

Does not re-render the component when value changes



---

🔹 Syntax

import { useRef } from "react";

const inputRef = useRef();


---

🔹 Example (Focus & Get Value)

import { useRef } from "react";

function App() {
  const inputRef = useRef();

  const handleClick = () => {
    console.log(inputRef.current.value);
    inputRef.current.focus();
  };

  return (
    <>
      <input type="text" ref={inputRef} />
      <button onClick={handleClick}>Click</button>
    </>
  );
}

export default App;

3️⃣ Controlled Component

🔹 What is Controlled Component?

Form data is controlled by React state

Uses useState

React has full control over input values



---

🔹 Example

import { useState } from "react";

function App() {
  const [user, setUser] = useState("");
  const [password, setPassword] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(user, password);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        value={user}
        onChange={(e) => setUser(e.target.value)}
        placeholder="Enter username"
      />

      <input
        type="password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        placeholder="Enter password"
      />

      <button>Submit</button>
    </form>
  );
}

export default App;

✅ Uses: Validation, live updates
❌ More code

4️⃣ Uncontrolled Component

🔹 What is Uncontrolled Component?

Form data is handled by DOM itself

Uses useRef

Less React control



---

🔹 Example

import { useRef } from "react";

function App() {
  const userRef = useRef();
  const passRef = useRef();

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(
      userRef.current.value,
      passRef.current.value
    );
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" ref={userRef} placeholder="Username" />
      <input type="password" ref={passRef} placeholder="Password" />
      <button>Submit</button>
    </form>
  );
}

export default App;

✅ Less code
❌ Less control

5️⃣ Props in React

🔹 What are Props?

Props = properties

Used to pass data from parent to child

Props are read-only



---

🔹 Parent Component

import User from "./User";

function App() {
  return (
    <>
      <User name="Amit" />
      <User name="Rahul" />
    </>
  );
}

export default App;


---

🔹 Child Component

function User(props) {
  return <h2>User Name: {props.name}</h2>;
}

export default User;


---

🔹 Using Destructuring

function User({ name }) {
  return <h2>User Name: {name}</h2>;
}
