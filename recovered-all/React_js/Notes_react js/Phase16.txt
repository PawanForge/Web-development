📘 Derived State in React JS


---

🔹 What is Derived State?

Derived State is a value that is calculated or derived from other state values or props inside a component.

It is NOT stored using useState.
It is created using simple variables or constants.


---

🔹 Examples of Derived State

const totalUsers = users.length;
const lastUser = users[users.length - 1];
const uniqueUsers = [...new Set(users)];

All these values are derived from users state.


---

🔹 Why Derived State?

If you store these values using useState:

const [totalUsers, setTotalUsers] = useState(0); ❌

You must update them again and again → bugs + mismatch state + dirty code.

Derived state avoids:

Duplicate state

Extra updates

Data inconsistency



---

🔹 Light Weight vs Heavy Weight

Type	Meaning

Light Weight	Normal variable (const total = users.length)
Heavy Weight	useState() (real application state)


Derived State is always Light Weight.


---

🔹 Rule

> If a value can be calculated from existing state or props,
DO NOT store it in useState. Use a variable instead.




---

📘 Complete Example

import { useState } from "react";

function App() {

  const [users, setUsers] = useState([]);
  const [user, setUser] = useState("");

  const handleAddUser = () => {
    setUsers([...users, user]);
    setUser("");
  };

  // Derived States
  const total = users.length;
  const last = users[users.length - 1];
  const unique = [...new Set(users)];

  return (
    <div>
      <input
        type="text"
        placeholder="add new user"
        value={user}
        onChange={(event) => setUser(event.target.value)}
      />

      <button onClick={handleAddUser}>Add User</button>

      <h2>Total User : {total}</h2>
      <h2>Last User : {last}</h2>
      <h2>Unique Total User : {unique.length}</h2>

      {users.map((item, index) => (
        <h4 key={index}>{item}</h4>
      ))}
    </div>
  );
}

export default App;


---

🔹 What is Set() here?

const unique = [...new Set(users)];

Removes duplicate values.

["Ram", "Shyam", "Ram"] → ["Ram", "Shyam"]


---

🔹 Purpose of Derived State

Benefit	Reason

Clean code	No extra state
No mismatch	One source of truth
Auto update	Always correct
Easy debug	No syncing logic
