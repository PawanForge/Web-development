So for proper interview preparation, function questions are usually asked in levels + types. Below is a complete practice roadmap of JS function questions, starting from basic → advanced, exactly how interviewers think.


---

1. Basic Function Questions (Foundation – must know)

Practice these first 👇

1. What is a function in JavaScript?


2. Difference between function declaration and function expression


3. What happens if a function does not return anything?


4. Can a function return an object / array / function?


5. How many times can return be used in a function?


6. What is the difference between:

return;
return {};
return undefined;


7. What will be the output:

function fn() {
  return "Hello";
  console.log("World");
}
console.log(fn());




---

2. Function Output–Based Questions (Very common)

Interviewers love predict the output questions.

Example types:

function fn() {
  return { a: 1 };
}
console.log(fn().a);

function fn() {
  return
  {
    name: "JS"
  };
}
console.log(fn());

👉 (Automatic Semicolon Insertion trap)

function fn() {
  return { x: 1 } + { y: 2 };
}
console.log(fn());

6. Hoisting & Function Questions (Asked a LOT)

fn();
function fn() {
  console.log("Hello");
}

fn();
const fn = function () {
  console.log("Hi");
};

❓ Why one works and the other doesn’t?


---

7. Return + Reference Questions (Based on your image 🔥)

Since your function returns an object, interviewers ask:

function fn() {
  return { count: 1 };
}
const obj = fn();
obj.count = 5;
console.log(fn().count);

❓ Why output is not changed?


---

8. Function as Value (Advanced Basics)

1. Can a function be stored in a variable?


2. Can a function be passed as an argument?


3. Can a function return another function?



function outer() {
  return function inner() {
    return "Hello";
  };
}
console.log(outer()());

9. this Keyword in Functions (Very Important 🔥)

1. this in normal function


2. this in arrow function


3. this inside object methods



const obj = {
  name: "JS",
  fn: function () {
    console.log(this.name);
  }
};
obj.fn();

10. Interview Tricky Function Questions

function fn() {
  return fn;
}
console.log(fn()());

function fn(a) {
  if (a) return fn;
  return "Done";
}
console.log(fn(1)(0));
