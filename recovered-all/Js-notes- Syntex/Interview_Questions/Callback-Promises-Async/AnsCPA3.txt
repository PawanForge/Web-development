
Async and await are used to write asynchronous code in a synchronous-looking way.
They do not convert async code into synchronous code, but they make it easier to read and understand.


---

🔹 async

An async function always returns a Promise

Even if you return a normal value, it is wrapped in a Promise


async function test() {
  return "Hello";
}

console.log(test()); // Promise { "Hello" }


---

🔹 await

await is used to wait for a Promise to resolve

It can be used only inside an async function

It pauses execution inside that function only, not the whole program


async function getData() {
  const result = await fetchData();
  console.log(result);
}


---

🔹 Error Handling (try / catch)

try block contains code that may throw an error

catch block handles the error or rejection


async function fetchUser() {
  try {
    const user = await getUserData();
    console.log(user);
  } catch (error) {
    console.log(error);
  }
}


---

❌ Important Corrections (Interview Traps)

❌ “Async converts async to sync”

✅ Correct:
Async/await does not make code synchronous, it only looks synchronous.


---

❌ “Await always exists with async”

❌ Wrong

✅ Correct:

await must be inside async

But async can exist without await


async function hello() {
  console.log("Hello");
}

✔ Valid code


---

❌ “try block define error”

❌ Wrong

✅ Correct:

try → code that might fail

catch → handles the error



---

🧠 One-Line Interview Answer (Perfect)

> “Async/await is syntactic sugar over Promises that allows asynchronous code to be written in a synchronous-looking manner with better readability and error handling.”
