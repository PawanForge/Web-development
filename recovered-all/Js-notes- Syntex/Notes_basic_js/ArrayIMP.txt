🧠 One-line interview explanation
map() stores the callback’s return value, and since arrow functions with {} need an explicit return, missing it results in undefined.
🔥 Quick memory rule
{} → must use return
No {} → auto return


✅ Correct ways to write it
✔ Option 1: Explicit return
Copy code
Js
let res = arr.map(x => {
  return x * 2;
});
✔ Option 2: Implicit return (no braces)
Copy code
Js
let res = arr.map(x => x * 2);
